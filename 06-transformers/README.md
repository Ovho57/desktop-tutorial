# Transformers & Attention

Learn self-attention, queries/keys/values, positional encodings, transformer blocks, and autoregressive text generation.

## Choose your route

- **New to this topic:** Follow the attention example slowly; it is the foundation of modern language models.
- **Already know the basics:** If you know transformer architecture, jump to the implementation challenge.

## What to do

1. Review the topic checklist above.
2. Work through examples and explain each step in your own words.
3. Complete the practice questions.
4. Build a small project that uses the concepts.
5. Save your code and notes in your own solutions folder.
