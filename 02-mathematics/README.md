# 📐 Math for AI

Build intuition for vectors, matrices, functions, graphs, probability, statistics, derivatives, and gradients.

## Choose your route

- **New to this topic:** Follow the visual explanations and solve the practice problems.
- **Already know the basics:** If you know linear algebra, probability, and calculus basics, use the checklist to identify gaps and continue.

1. Review the topic checklist above.
2. Work through examples and explain each step in your own words.
3. Complete the practice questions.
4. Build a small project that uses the concepts.
5. Save your code and notes in your own solutions folder.
