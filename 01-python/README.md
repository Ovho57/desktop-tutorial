# Python Foundations

Learn the language used throughout this course: variables, types, conditions, loops, functions, collections, files, exceptions, modules, classes, and NumPy.

## Choose your route

- **New to this topic:** Complete every lesson and type each example yourself.
- **Already know the basics:** Experienced Python users: take the quick challenge in this module, then move to Mathematics or Machine Learning.

## What to do

1. Review the topic checklist above.
2. Work through examples and explain each step in your own words.
3. Complete the practice questions.
4. Build a small project that uses the concepts.
5. Save your code and notes in your own solutions folder.
