# AI From Scratch — Desktop Tutorial

A step-by-step learning path for building your own AI, starting from programming fundamentals and progressing to language models and deployment.

## Learning path

1. **Setup** — install Python, Git, and your development tools.
2. **Python** — variables, control flow, functions, data structures, files, errors, modules, classes, and NumPy.
3. **Mathematics** — vectors, matrices, functions, graphs, probability, statistics, and calculus essentials.
4. **Machine learning** — datasets, preprocessing, training, validation, evaluation, regression, and classification.
5. **Neural networks** — neurons, layers, activations, loss functions, backpropagation, and optimization.
6. **Natural language processing** — text cleaning, tokenization, vocabularies, embeddings, and language modeling.
7. **Transformers** — attention, self-attention, positional information, transformer blocks, and generation.
8. **Training a model** — preparing data, batching, training loops, checkpoints, and evaluation.
9. **Engineering and deployment** — APIs, inference, testing, performance, safety, and deployment.

## How to use this repository

- Work through the numbered lessons in order.
- Type the examples yourself instead of only reading them.
- Complete each lesson's questions before moving on.
- Save your answers and experiments in a personal folder.
- Build the module project before starting the next module.

## Clone the repository

```bash
git clone https://github.com/Ovho57/desktop-tutorial.git
cd desktop-tutorial
```

Open the folder in your editor and begin with the setup module.

## Course structure

The complete course is organized into numbered modules, lesson notes, module projects, and a place to save your solutions. The detailed lesson files are being added to this repository separately.
