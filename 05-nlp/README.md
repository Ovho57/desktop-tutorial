# 05 — Natural Language Processing

Learn how computers turn text into tokens, IDs, vectors, and sequences that a neural network can process.

**How to study:** Read the chapters in order. Each chapter teaches the vocabulary and ideas before asking you to use them. Work through the examples with your own code, answer the questions without looking back, and complete the practice task before moving on.

## Chapters

1. [Chapter 1 — How Computers Represent Text](01-how-computers-represent-text.md)
2. [Chapter 2 — Embeddings and Sequences](02-embeddings-and-sequences.md)

## Study method

1. Read one chapter slowly; do not skip unfamiliar terms.
2. Type the code examples yourself instead of only copying and pasting.
3. Predict what each example will do before running it.
4. Answer the checkpoint questions in your own words.
5. Complete the practice task and keep your work in your own project folder.
6. If an answer is wrong, return to the explanation and find the exact idea you misunderstood.
