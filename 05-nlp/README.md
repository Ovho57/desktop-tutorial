# 💬 Natural Language Processing

Turn text into data with cleaning, tokenization, vocabularies, embeddings, sequence modeling, and language-model basics.

## Choose your route

- **New to this topic:** Start with text preprocessing and build a tiny next-word predictor.
- **Already know the basics:** Experienced NLP learners: review tokenization and embeddings, then continue to Transformers.

## What to do

1. Review the topic checklist above.
2. Work through examples and explain each step in your own words.
3. Complete the practice questions.
4. Build a small project that uses the concepts.
5. Save your code and notes in your own solutions folder.
