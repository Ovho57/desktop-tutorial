# Neural Networks

Discover neurons, layers, activation functions, loss, gradient descent, backpropagation, optimizers, and training loops.

## Choose your route

- **New to this topic:** Build a tiny network step by step; focus on what each calculation means.
- **Already know the basics:** If you have trained neural networks before, skip to the from-scratch implementation challenge.

## What to do

1. Review the topic checklist above.
2. Work through examples and explain each step in your own words.
3. Complete the practice questions.
4. Build a small project that uses the concepts.
5. Save your code and notes in your own solutions folder.
